# For Mom & Dad — what I need to publish Focus Agent

Hi! This doc explains what I built, what I'm asking you to do, and what is
(and isn't) happening with money and data. Written so it takes ~5 minutes.

## What Focus Agent is

A Chrome extension I built that reads my own school assignment list from the
Poly portal and coaches me to actually start my homework — a focus timer,
streaks, a "panic button" that triages what's due, and reminders when I
drift to YouTube mid-session. It's deliberately designed to NOT do homework
for me (it refuses if you ask it to write anything).

I want to publish it on the Chrome Web Store — **unlisted at first**, which
means only people with the direct link can install it (me, and classmates I
share it with). If it works well, we'd flip it to public later.

## What I'm asking you to do (2 things)

1. **Read PRIVACY.md** (in this folder, ~2 min). Short version: everything
   stays on the user's device. No server, no accounts, no analytics, nothing
   is collected or sent anywhere. I need a parent to approve it before it
   goes on a public page, and we need to pick a contact email to list —
   ideally one you're okay being semi-public.
2. **Register the Chrome Web Store developer account.** Google requires the
   account holder to be 18+, so it needs to be under your Google account.
   It's a one-time $5 fee at https://chrome.google.com/webstore/devconsole.
   I'll sit with you and do the actual listing — I just need the account.

## What is NOT happening (yet)

- **No money changes hands.** The extension is free. No payments, no
  subscriptions, no ads. If I ever add a paid version (maybe this fall),
  that's a separate conversation and would need a payment account set up
  with you.
- **No data collection.** See PRIVACY.md — there's literally no server.
- **No AI backend in the store version.** I have an AI coach feature, but
  it only runs locally on my machine; the version going to the store has it
  stripped out and uses built-in rules instead.

## Why I want to do this

This is part of a bigger plan I'm working on: learning to build and ship
real products now, so I have those skills (and a track record) when I start
a company someday. Publishing this — store review, privacy policy, real
users — is the skill I'm practicing. The $5 is the entire cost.

Questions? Ask me — or the PRIVACY.md and STORE.md files in this folder
have the full details.
